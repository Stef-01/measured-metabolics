# Patient testimonial portraits

Drop square JPGs here to replace the initials-fallback avatars in the
testimonials section. Filenames must match the slugs used in `Quotes()`:

- sarah.jpg
- daniel.jpg
- aisha.jpg
- james.jpg
- priya.jpg
- tom.jpg

Recommended: 400×400, sRGB, warm natural light, authentic (see
`docs/image-brief.md` prompt 3.3). Until a file exists, the UI shows the
coloured-initials fallback automatically. Use real, consented patient photos
before launch, AI faces can mislead in a medical-testimonial context.
