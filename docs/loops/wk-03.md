## Loop 1 (Thu → Fri) · red-team + fix

- **Red-team simulated 5-meal sweep:** for every keyboard letter A→A→F→A→A (approve, approve, flag, approve, approve), the queue advances and the toast confirms. Time elapsed in session counter < 5 min trivially (instant).
- **Findings:**
  - 4 `react-hooks/purity`/`refs`/`immutability` errors on the queue screen: `handleAction` was used before declaration in the keyboard `useEffect`; `Date.now()` and `useRef.current` were called in render to compute elapsed time. Refactored: hoisted `handleAction` inside `useCallback` above the keyboard effect, replaced the ref-based session start with `useState(() => null)` plus a one-shot `useEffect` to set it, replaced render-time `Date.now()` with a 1Hz `tick` state that re-renders the timer.
  - 1 dependency-array warning on the keyboard effect — fixed by depending on stable `handleAction` callback.
  - `pnpm lint:fix` reformatted 8 files.
- **Fixes shipped:** all of the above.
