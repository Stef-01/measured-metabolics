# Week 2 — Stage 2: Patient PWA, all 8 screens

**Status:** GREEN · ship gate passed
**Stage:** 2 — Patient PWA with mock + localStorage state
**Build dates:** 2026-05-22

## Build (Mon → Wed)

- `lib/storage/patient-store.ts` — typed localStorage namespace `measured.patient.{pid}.{entity}` with `useSyncExternalStore`-driven hooks (`useStoredMeals`, `useStoredSymptoms`, `useStoredThread`) and a `useSeedPatientStore` idempotent seed-on-mount helper. Cross-tab via `storage` events.
- `components/patient/app-header.tsx` — sticky header with eyebrow + serif title + trailing slot.
- `components/patient/escalation-card.tsx` — red triage card with single Send-now CTA. Used on Home (when last symptom is severe) and on Symptoms (when this submission is severe).
- 8 screen components under `components/patient/screens/`:
  1. `home-screen` — week eyebrow, Snap-a-meal primary CTA, plan / metrics / messages cards, escalation banner if severe symptom present.
  2. `meal-capture-screen` — getUserMedia camera (rear-facing where supported), `<input type="file" capture="environment">` fallback, draft autosave (mealType + note + photoDataUrl), meal-type chips, save → push to `/p/meal/saved?id=…`.
  3. `meal-saved-screen` — animated tick + meal label + "see plan" CTA.
  4. `plan-screen` — 4 plan items (breakfast/lunch/dinner/snack) with rationale boxes; tapping a meal navigates to `/p/plan/[slug]`.
  5. `[slug]/page.tsx` — recipe detail (why-this-meal block + ingredient list).
  6. `metrics-screen` — Recharts AreaChart for CGM (with `ReferenceArea` for 3.9–10 mmol/L target band), LineChart for weight, LineChart for symptom severity over time. 3-tab pill switcher.
  7. `symptoms-screen` — 5 chip rows (nausea, constipation, appetite, hypos, meds-as-planned). Severe → escalation card surfaces inline; non-severe → auto-bounce home.
  8. `messages-screen` — sticky composer, animated bubble list, Enter sends, autoscrolls to newest.
- DeviceFrame already gates phone-frame on `/p/*` only (Week 1) so all of these render in the bezel on desktop.
