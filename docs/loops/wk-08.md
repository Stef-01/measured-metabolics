# Week 8 — Stage 7 (Compliance: consent, audit viewer, escalation, PDFs)

## Build (Mon–Wed)

### 3-tier consent (PRD §16.2)

- `/onboarding/consent` — three independent toggles (clinical_care required; rwe + marketing optional). Submit lands the patient in `/p/home`.
- `/p/settings/privacy` — withdraw RWE / marketing without affecting clinical_care. Withdrawal records carry `meta.isolation: "rwe withdrawal does not affect clinical_care"` so the audit log reflects the policy, not just the action.
- `src/server/services/consent.ts` — `readConsent`, `grantConsent`, `withdrawConsent` with audit calls; `CONSENT_VERSION = "1.0.0"` so versioning bumps are explicit.

### Audit viewer

- `/admin/{audit,organizations,users}` — admin shell with sidebar nav.
- `/admin/audit` — append-only table; `?action=` and `?patient=` query filters; vibe-mode shows a 3-row fixture so the layout is verifiable without a Supabase connection.
- Layout enforces visual stability so Stage 8 can swap rows for the real query without re-laying anything out.

### Escalation rules (PRD §16.5 — 7 triggers)

- `src/server/escalation.ts` — `evaluateEscalation()` returns `{ triggered, ruleId, copy, alertDietitian }` and writes an audit row when a rule matches.
- `matchEscalation()` is a pure-logic variant for unit tests. PRD-mandated rules:
  1. `e1-severe-hypo` — severe hypo or fainting.
  2. `e2-severe-nausea-72h` — severe nausea persisting >72h.
  3. `e3-suicidality` — explicit keywords or severe mental_health.
  4. `e4-medication-non-adherence-7d` — missed/skipped doses for 7 days.
  5. `e5-rapid-weight-loss` — rapid >3kg or >5kg.
  6. `e6-severe-constipation-2w` — severe constipation 2 weeks.
  7. `e7-cgm-extreme` — severe CGM or extreme readings (<3 / >20 mmol/L).
- Copy is intentionally _non-emergency_: Lifeline / 000 / dietitian-alerted phrasing — Measured never claims real-time emergency capacity.

### PDFs (React PDF)

- `src/lib/pdf/dietitian-report.tsx` — A4, 30-second summary + recommendations.
- `src/lib/pdf/care-plan.tsx` — A4 problems / goals / team / review-due.
- `src/app/api/reports/[id]/pdf/route.tsx` — POST returning `application/pdf`. Resolves via Supabase when configured; otherwise renders fixture copy. Audits `report.sent` before streaming.

### Permission matrix (PRD §22.2 expansion)

- `tests/permissions/resources.test.ts` — full role × resource × action sweep (14 resources × 4 roles × 2 actions = 112 cells, plus invariants for audit append-only and billing-suggestions GP-only). Every cell is encoded _from_ the policy SQL so divergence shows up as an instant red-line in CI.
